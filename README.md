# 嘉明湖沿線氣溫

11/6–11/8 戒茂斯上嘉明湖・向陽出的沿線氣溫與預報，每天中午自動更新。

網頁：https://debbieyu605-cyber.github.io/2026Cidanumasbuan/

資料來源：中央氣象署（登山與森林遊樂區一週預報、雨量站）、Open-Meteo（ECMWF、GFS 格點預報）。數字為預報，實際以現場與官方公告為準。

## 上山沒訊號怎麼看

- 網頁有離線快取（`sw.js`）。出發前在有訊號的地方用 Safari 開過一次，之後沒網路也能開，頁面會標示資料是幾點的。iPhone 建議「加入主畫面」後從主畫面開。
- 頁面上的「下載離線版」會把當下的頁面、圖表程式和資料打包成一個 HTML 檔（`jiaminghu_offline_月日_時分.html`），存到手機「檔案」裡，離線也能直接點開。
- `d3.min.js` 放在 repo 內（原本從 CDN 載入），離線時才載得到。

每天的排程只更新 `data.json`，不動其他檔案。
